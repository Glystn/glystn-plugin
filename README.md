# Glystn for Claude

The Glystn plugin connects Claude to [Glystn](https://glystn.com), which searches what creators actually say in Instagram and TikTok videos, and adds skills for the research Glystn customers do most: sizing trends, share of voice, finding and vetting creators, paid creator scans, analyzing posts at scale, trend maps, hives and creator content strategy.

The plugin is in [`plugins/glystn`](plugins/glystn); its [README](plugins/glystn/README.md) lists the skills and what the plugin connects to. You need a Glystn account to sign in.

## Install

In Claude Code:

```
/plugin marketplace add Glystn/glystn-plugin
/plugin install glystn@glystn
```
